# Buttondown page copy

Text for the public newsletter page at `buttondown.com/riseregenerate`, which
is where the "Subscribe" form on riselabs.at sends people, and what they see if
they find the newsletter any other way. Buttondown's default copy is generic
filler; this replaces it.

Paste each block into the matching field in **Buttondown → Settings**.

---

## Newsletter name

```
RISE — notes from the institute
```

---

## Tagline / short description

Used in listings, search results and the browser tab.

```
Occasional notes on whole life carbon, building data and what comes after efficiency. From RISE, a research institute in Vienna.
```

---

## About / page description

The main block on the subscribe page.

```
RISE is a research institute in Vienna working on the deep decarbonisation of
the built environment — in European policy, in international collaborations,
and with the practitioners already building differently.

This is where we write up what we are finding before it becomes a paper, and
what is moving in policy before it becomes a requirement. Expect: new work and
publications as they land, what is changing in whole life carbon regulation and
what it will actually ask of people, data and tools we have opened up, and the
occasional argument we think is worth having.

A few times a year. No tracking, no sales sequence, and one click to leave.
```

---

## Confirmation page / welcome message

Shown after someone subscribes.

```
You're on the list. Nothing will arrive for a while — we write when there is
something worth sending, which is a few times a year rather than a few times a
month.

In the meantime, our current work is at riselabs.at/projects, and everything we
publish is at riselabs.at/publications.
```

---

## A note on the promises above

Three claims in this copy are commitments, not decoration, and the site has to
keep matching them:

- **"A few times a year."** Say it and mean it. If the newsletter becomes
  monthly, change this line first.
- **"No tracking."** Buttondown can track opens and clicks. If you turn that
  on, this line has to go, and `/datenschutz/` needs a sentence about it.
- **"One click to leave."** True by default — Buttondown puts an unsubscribe
  link in every email. Don't remove it.

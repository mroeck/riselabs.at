# Publications with no project, and the projects that are missing

Where the running record of that question lives. Martin worked through his
own 21 on 30 October 2026, through the interactive list at
https://claude.ai/artifact/PMdgZRFo5S2XeojBBiUa3C

Three outcomes are possible for each publication, and all three are useful:

- **a project on the site** - written into the publication's `projects:`, so
  it appears under "Publications on this project" on that project's page;
- **standalone** - nothing to do, and nothing is recorded in the file. The
  entry below says so, so nobody re-opens the question;
- **a project the site does not have** - recorded here, because the
  publication cannot point at a project file that does not exist.

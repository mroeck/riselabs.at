{%- comment -%} One publication, formatted as a citation. Expects: include.pub Any RISE person's `cite` name is underlined automatically. {%- endcomment -%} {%- assign p = include.pub -%} {%- assign a = p.authors -%} {%- comment -%} Every form a person has published under, not just the current one. A name in an author string is the name that paper carries, and people's names change: Zuhaib published as "Zuhaib S" until 2022 and as "Batra Z" from 2024, under one ORCID. Matching only the current form would leave half of someone's own work looking like a stranger's. `cite` first, then anything in `cite_also`. The longest form has to go first within a person, or a shorter one can match inside a longer one and break the markup. {%- endcomment -%} {%- for person in site.people -%} {%- if person.cite -%} {%- capture wrapped %}{{ person.cite }}{% endcapture -%} {%- assign a = a | replace: person.cite, wrapped -%} {%- endif -%} {%- for also in person.cite_also -%} {%- capture wrapped_also %}{{ also }}{% endcapture -%} {%- assign a = a | replace: also, wrapped_also -%} {%- endfor -%} {%- endfor -%} {%- comment -%} Is this work RISE or GBDI did, or work the author did before joining? Derived, never tagged by hand: a publication counts if any person on it has a `rise_since` year in their file and the publication is from that year or later. `rise_since` is one fact per person, and it is the only thing here a file cannot work out for itself: an author string says who wrote a paper, not who they worked for at the time. Being attached to a project is deliberately NOT enough. Several projects on this site ran before RISE existed - IEA EBC Annex 72 ended in 2023 - so "has a project" would have counted 2022 work as RISE work. The date a person joined is the only thing that actually answers the question. Nobody with no `rise_since` is ever counted, so the filter simply does not appear until those years exist. It never guesses. {%- endcomment -%} {%- assign rise_work = false -%} {%- for slug in p.people -%} {%- assign who = site.people | where: "slug", slug | first -%} {%- if who.rise_since and p.year >= who.rise_since %}{% assign rise_work = true %}{% endif -%} {%- endfor -%} {%- comment -%} The thumbnail. Every publication has one: a title page where the licence allows it, otherwise a designed tile. The three whose title pages are CC-BY-NC-ND have neither yet (H20), and they fall through to the tile drawn below in HTML, from the entry's own front matter - so a publication added tomorrow with no image still looks like the others rather than leaving a hole. Decorative, with empty alt text: the citation beside it says everything the picture does, and a screen reader announcing "title page of..." before every entry in a list of sixty-four would be noise. {%- endcomment -%} {%- if p.thumbnail -%} {%- else -%} {{ p.kind | default: "publication" }} {{ p.year }} {%- endif -%} {{ a }}. {{ p.title }}. {%- if p.journal %} {{ p.journal }},{% endif %} {{ p.year }}. {%- if p.doi %} https://doi.org/{{ p.doi }}{% endif -%} {%- if p.note %} - {{ p.note }}{% endif -%}

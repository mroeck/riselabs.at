Expects: include.posts. include.featured="true" lets the first post with `featured: true` lead at full width, which is the "All" tab only; inside a tab or while filtering it is an ordinary card. Each card is one link. The picture is the post's `hero` where it has one, otherwise a tile in the CI gradient carrying the type's label, with a different gradient per type so a grid of tiles does not read as one block. Event tiles also carry the event date.

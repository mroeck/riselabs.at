{%- comment -%} How much we work with one partner, as three counts. include.pa a partner document Projects - where they are named as client or as collaborator, counted once even if they are both Papers - publications listing them among the co-author affiliations News - posts that name them in their `partners:` list, and only those. This used to also count posts attached to any project the partner works on, because posts did not carry partners at the time. They do now, and two definitions meant this column and the partner's own page disagreed for nine partners. One rule: a post is connected to a partner when the post says so. A dash here means a post still needs its partners flagged, which is useful to see. A zero renders as a dash: an empty cell reads as missing data, a dash reads as none, and those are different claims. {%- endcomment -%} {%- assign slug = include.pa.slug -%} {%- assign as_client = site.projects | where_exp: "p", "p.clients contains slug" -%} {%- assign as_partner = site.projects | where_exp: "p", "p.partners contains slug" -%} {%- comment -%} counted once if they are client and collaborator both {%- endcomment -%} {%- assign n_projects = 0 -%} {%- for p in site.projects -%} {%- if p.clients contains slug or p.partners contains slug -%} {%- assign n_projects = n_projects | plus: 1 -%} {%- endif -%} {%- endfor -%} {%- assign pubs = site.publications | where_exp: "p", "p.partners contains slug" -%} {%- assign n_pubs = pubs.size -%} {%- assign news = site.posts | where_exp: "p", "p.partners contains slug" -%} {%- assign n_news = news.size -%} {% if n_projects == 0 %}–{% else %}{{ n_projects }}{% endif %} {% if n_pubs == 0 %}–{% else %}{{ n_pubs }}{% endif %} {% if n_news == 0 %}–{% else %}{{ n_news }}{% endif %}

{%- comment -%} Newsletter signup. Two ways to wire it, set in _config.yml: newsletter_url a link to your public Buttondown page (https://buttondown.com/riseregenerate) → renders a button; subscribing happens on Buttondown newsletter_action the API embed endpoint (https://buttondown.com/api/emails/embed-subscribe/riseregenerate) → renders a form; subscribing happens here These are different URLs and not interchangeable: posting a form to the page URL does not subscribe anyone. If both are set, the form wins and the page link sits beneath it. With neither set the block falls back to an email link, so the page never shows a control that cannot work. {%- endcomment -%}

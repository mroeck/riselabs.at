{%- comment -%} The facts box. There is no "Cite as" row. A project is not a citable work: most of these were done with partners, and a citation line on the page invites someone to cite RISE for a piece of work RISE contributed to rather than authored. Citations belong to publications, which have authors, a venue and a DOI. If a project produced something citable, that something is a file in _publications/ and gets its citation there. Funder and client are one row. They named the same organisation on all fifteen projects, because the body paying for the work is the body that commissioned it; two rows repeating one name read as two different facts. Where `clients` names partners we show those, because they link to the partner's own page; `funder` is the free-text fallback, and is shown alongside when it says something the partner names do not (IEA EBC Annex 72 names an Austrian co-funder that has no partner page). {%- endcomment -%} {%- comment -%} Is the funder text saying anything the client links do not?
